📖 Sobre o site

O CineBlog é um projeto desenvolvido utilizando HTML, CSS e JavaScript. O objetivo é criar um site simples para apresentar filmes e praticar desenvolvimento web.

As imagens utilizadas ficam armazenadas dentro da pasta img.
