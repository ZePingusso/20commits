# Meu Site de Filmes

Este projeto é um site básico desenvolvido utilizando HTML, CSS e JavaScript.

## Arquivos

- index.html: página principal do site.
- style.css: responsável pelo estilo da página.
- script.js: responsável pelas funções do site.
- erro.txt: arquivo para registrar possíveis erros.
- img/: pasta que contém as imagens utilizadas.
- README.md: documentação do projeto.

## Tecnologias utilizadas

- HTML
- CSS
- JavaScript

## Imagens

O site utiliza três imagens armazenadas na pasta `img`.

## Funcionamento

O arquivo `index.html` utiliza o arquivo `style.css` para a aparência e o arquivo `script.js` para as funções.
