# 🎬 CineBlog

Site desenvolvido para praticar HTML, CSS e JavaScript.

## 📁 Estrutura

O projeto possui os seguintes arquivos:

- index.html
- style.css
- script.js
- erro.txt
- README.md

Também possui uma pasta chamada `img`, onde estão armazenadas três imagens.

## 🛠️ Tecnologias

- HTML
- CSS
- JavaScript

## 📷 Imagens

Foram utilizadas três imagens no site.

As imagens estão dentro da pasta:

`img/`

E são utilizadas no arquivo `index.html`.

## 🎨 CSS

O arquivo `style.css` é responsável pela aparência do site.

Ele é conectado ao HTML através da tag:

`<link rel="stylesheet" href="style.css">`

## ⚙️ JavaScript

O arquivo `script.js` é responsável pelas funções do site.

Ele é conectado ao HTML através da tag:

`<script src="script.js"></script>`

## ✏️ Alterações

Os arquivos podem ser alterados diretamente pelo VS Code.

## 🗑️ Exclusão

Arquivos que não forem mais necessários podem ser excluídos da pasta do projeto.

## 📱 Responsividade

O site possui uma configuração para funcionar melhor em telas menores, como celulares.

## 📌 Objetivo

O objetivo do projeto é praticar a criação e organização de arquivos em um projeto web.
